## Agents.md

### Project Overview
O projeto atual é uma POC com foco em testar a viabilidade do uso de alguns rich text editors como CkEditor ou Tiny para criação de templates de documentos. Esse projeto tem como objetivo os pontos a seguir:

- Criar templates com cabeçalho, corpo contendo campos editáveis e footer
- Ser possível renderizá-los e edita-los on the fly
- Gerar PDFs usando o template criado e com os valores fornecidos

### Code conventions
Como code style utilizaremos o padrão do google javascript/typescript, atente-se a esse ponto quando for gerar código javascript/typescript garantindo a formatação correta e seguindo as guidelines definidas.
